1. Purpose

This runbook defines how to operate the VMware weekly health check automation for the SixFlags vCenter only during Phase 1. The design is aligned with the current manual health check workbook, where SixFlags includes ESXi hosts, storage and backup infrastructure entries, and physical inspection fields such as power supply status, disk status, LED status, fan status, cooling, PDU status, cable management, cleanliness and remarks.

Corrected automation position: VMware and vSphere health checks are treated as automated. Hardware sensor items are treated as mostly automated when exposed through vCenter. Only true visual/physical inspection items remain manual.

4. Weekly Run Procedure
  1. Place the latest physical inspection workbook in C:\VMwareHealthCheck\Input if physical findings are available.
  2. Open PowerShell as the engineer account.
  3. Run cd C:\VMwareHealthCheck.
  4. Run .\Run-VMwareHealthCheck.ps1.
  5. Confirm only the SixFlags vCenter is enabled in Config\VCenters.csv.
  6. Review the generated HTML report first.
  7. Review Excel details for inventory, findings, capacity and raw data.
  8. Review the log file for connection or permission warnings.
  9. Review Critical and Warning findings.
  10. Review physical-only checklist items: labeling, cable management, cleanliness, rack verification, fan noise, physical condition, PDU physical verification and humidity.
  11. Update the action tracker.
  12. Archive reports with the weekly physical inspection workbook.
